# supplier-crud-technical-challenge
A Python Flask and PostgreSQL supplier management application demonstrating CRUD operations and local-to-cloud database synchronisation.

# -------------------------
What you built and why?

Since late August 2026 after work, I have been working on a Purchase Ledger financial system called Purchase Web.  This is a personal project in order to re-learn various modern and old coding languages, and development tools. It is a basic stack configuration containing suppliers, purchases, payments, ledger, reports, settings, and an AI Assistant called Mara. I have nearly completed the full architecure in terms of connections through Flask backend and frontend.  The Supplier section is fully working in a basic fashion with CRUD operations which originally wrote to SQLite3, but now transitioned to using PostgreSQL. The basic stack currently utilises: Python | Flask | PostgreSQL | HTML | CSS | Jinja2 | JavaScript, using DevOps Visual Code | GitHub | Bash.

For this Technical Challenge I have decided to utilise the Supplier section and improve upon it.  Given the deadline and time I have I will try to:
  1. I have two options in Suppliers called where a user can view a list of supplier accounts and supplier addresses. I will improve on this list         and add another option to search on a supplier name from the database, and output the information.
  2. To improve the output by making it more responsive, no matter the type of technology used - Responsive Web Design (RWD). These improvements          will be to the sidebar and main container screens. I hope to make the sidebar open or closed when the mouse is moved to the left of the screen,      and have a button that allows a user to click a box and keep the sidebar in view. I use two methods to navigate around Purchase Web. The web         ends at West, North Nest, North, North East, East, South, and two links at the centre, one for returning to the main menu and the other a link       for Mara AI Assistant. These links are currently out of position, and do not stay in position when zooming in and out, or for different              screens. I intend to make sure they are fixed for every type of user.
  3. Incorporate an online Cloud storage, so when a supplier is added, amended or deleted, the PostgreSQL database in the cloud is also updated. I        intend to try and use synchronisation to ensure the update, even if a connection is not available at the time, and queued for update later.
